# 아이디어 소개서 요약

원본: 「2026 AI활용 전국 대학생 창업 해커톤 대회 아이디어 소개서」 (개인정보 동의서 페이지가 있어 PDF 원본은 저장소에 올리지 않음)

- **아이디어명**: 풀이봄 — 중학생의 수학 풀이를 분석해 교사의 맞춤 지도를 돕는 AI 서비스
- **분야**: 지역 간 교육격차, 학습지원, 교육 접근성 개선(AI 활용)

## 1. 지역문제 정의

- 강원지역 고교 재학생 수능 수학 표준점수 평균: 2022~2026학년도 **5년 연속 전국 17개 시도 중 최하위**
  - 2026학년도 평균 92.1점 (전국 97.0점, −4.9점) / 수학 1·2등급 비율 강원 4.7%, 전국 9.8%
  - 출처: 강원일보, 「강원 수험생 최대 약점 '수학'…지역 격차 5년새 최대」, 2026.10.18.
- 고교 성적만으로는 원인을 알 수 없음 → **중학교 단계**에서 학습 결손을 조기 발견하는 데 집중
- 2025 전국 초·중·고 수학교육 인식 조사 (사교육걱정없는세상·강경숙 의원실, 2026.1.27. 발표)
  - '수학 포기하고 싶다': 초6 17.9% → 중3 32.9% → 고2 40.0%
  - 포기 원인: 중3 학생은 '문제가 어려워서' 44.7%, 중학교 교사는 '기초학력 부족·누적된 학습결손' 45.5%
  - 교사 80명 중 70명(87.5%)이 수포자 문제를 '심각'하다고 응답
  - 지도 어려움: '학생 간 수준 차이' 33.7%, '지도 시간 부족' 25.4%

→ 문제: 점수 뒤의 학습 결손을 구체적으로 파악하고, 제한된 시간 안에 학생별 보충 지도로 연결하기 어렵다.

## 2. 문제 해결 목표 / 기대효과

- **학생**: 반복 오류 보완, 재풀이로 개선 경험 → 자신감 회복
- **교사**: 원본 풀이·오류 의심 단계·반복 취약 개념을 근거로 제공 → 분석·정리 부담 완화, 소그룹 지도 계획
- **학교**: '취약점 확인 → 보충 지도 → 재풀이 → 변화 확인' 순환
- 실증 지표: 교사 풀이 검토·자료 정리 시간, 보충 지도 전후 동등 난도 문항 정답률, 반복 오류 빈도, 사용자 의견
- 백월 문구: 교사가 원본 풀이·관찰 메모를 함께 보고 학생별 성장 사례를 **교과 세특 작성 참고자료**로 활용

## 3. AI 적용

| 단계 | 모델 | 역할 |
|---|---|---|
| 문항 구조화 | 업스테이지 Document Parse | 문제지에서 문항 번호·내용·수식·도형 영역 추출, 문항별 구분 |
| 손글씨 인식 | 업스테이지 Document OCR | 풀이 문자·숫자 + 위치 정보 추출, 태블릿 필기 위치·시점과 결합 |
| 풀이 분석 | LG AI연구원 EXAONE 4.5 | 원본 이미지 + OCR + 교사 검토 정답·해설 → 처음 오류 의심 단계, 오류 유형(부호 계산·동류항 정리·등식 변형), 관련 개념. 정답이어도 중간 과정 검토 |
| 종합·지도 제안 | 업스테이지 Solar Pro 4 | 풀이 시간·정오답·수정/재풀이 이력 결합 → 학생별 요약, 취약 개념·지도 우선순위, 보충 질문·연습 문항, 소그룹 묶기 |

원칙
- 국내 모델 우선, 실제 손글씨·수식으로 정확도 검증, 처리 시간·비용 비교 후 구성 결정
- 학생 식별정보는 분석 입력에서 제외, 필요한 풀이 영역만 외부 AI로 전달
- 한 번의 오답으로 개념 부족 확정 X / 풀이 시간 길다고 이해 부족 판단 X / 필기 순서 = 사고 순서로 단정 X
- 판독 어렵거나 근거 부족 → **'확인 필요'** 표시, 최종 판단은 교사

예시: `2x+3=11` → `2x=11+3` 으로 바꾼 경우 → 등식 변형(이항 부호) 확인 제안

## 4. 실행 구상

초기 대상: **중1 '문자와 식 · 일차방정식'**

1. 필수 개념 진단·맞춤 문항: 교사가 학년·단원 선택 → 검토된 문항 틀에서 숫자·조건 바꿔 생성 → 정답·난이도 검증 + 교사 확인 후 배정
2. 풀이·학습 기록 수집: 원본 필기, 최종 답안, 풀이 시간, 수정·재풀이 이력, 화면 이탈·장시간 무입력 구간
3. 학급 데이터 통합 조회·정렬: 학급·과제·기간·취약 개념·제출 상태 필터, 정답률·반복 오류 정렬
4. 근거 확인·보충 지도: 원본 풀이, 오류 의심 위치·이유, 이전 기록, 분석 수정, 관찰 메모, 소그룹/개별 과제
5. AI 유사 문항 재풀이·변화 반영

필요 자원: 문항·정답·해설, 선행 개념 연결표, 오류 유형 정의, 손글씨 검증 자료(정상 풀이·계산/개념 오류·수정 흔적·판독 어려운 필기), 서버·DB·이미지 저장소, 학급별 접근 권한

시연: 가상 데이터 화면과 실제 AI 처리 결과를 **구분해서** 제시
