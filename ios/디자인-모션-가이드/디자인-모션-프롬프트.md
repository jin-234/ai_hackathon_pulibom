## 프롬프트

풀이봄 학생 앱의 화면과 움직임을 아래 기준에 **정확히** 맞춰 줘. 첨부한 영상·스크린샷과 같은 느낌이 나야 한다.

### 1. 전체 분위기

- **따뜻한 크림 + 병아리 노랑 + 세이지 그린**. 귀엽지만 유치하지 않게, 둥글고 부드럽게. 그림자는 옅고 넓게.
- 항상 밝은 화면(다크 모드여도 밝게). 글자는 진한 먹색(ink), 보조 글자는 따뜻한 회갈색(muted).
- 마스코트는 **새싹 달린 노란 병아리**(둥근 몸, 점 눈, 분홍 볼, 주황 부리·발). 시작 화면·로그인·빈 화면·포스트잇·축하 화면에 나오고 늘 조금씩 움직인다.
- 한국어 문구는 "~해요" 체로 짧고 다정하게.

### 3. 모양·크기

- 모서리: 카드 24~28, 입력 묶음 20, 큰 버튼 18, 말풍선 16(보낸 쪽 아래 모서리만 5), 알약은 완전 둥글게.
- 큰 버튼 높이 56(honey, 글자 headline ink). 입력 줄 높이 56, 라벨 폭 84, 값은 오른쪽 정렬 title3.
- 상단 바 64(cream, 아래 1px line). 하단 탭 바: 아이콘 21 + 캡션, 선택 칸 honeySoft 둥근 사각형(16).
- 아이콘은 SF Symbols, 굵기 semibold 근처. 로고 텍스트 "풀이봄." 은 heavy, 마침표만 honeyDeep.

### 4. 화면별 모습 (스크린샷 참고)

- **시작 화면**: 그라데이션 가운데 큰 병아리(190) + 아래 "풀이봄."(52 heavy) + "풀이를 모아, 배움을 잇다"(olive). 앱 아이콘을 누른 직후 기본 화면도 honeySoft 로 맞춰 번쩍임 없이.
- **로그인**: 세로는 위 1/3 영웅 영역(병아리 110·로고 32)·아래 입력, 가로는 왼쪽 44% 영웅(병아리 180·로고 44)·오른쪽 입력. 큰 제목 "로그인", 설정 앱 같은 묶음(반 / 번호 / 비밀번호), 주 버튼, honeyDeep 링크 "반 코드로 회원가입", 작은 회색 둘러보기·데모 안내.
- **과제 목록**: 상단 바(병아리+풀이봄., 오른쪽 💬 원형 버튼과 이름 알약) / 인사말(연필 든 병아리 + "OO, 오늘은 **어떤 문제를 풀어 볼까요?**"(뒷부분 olive)) / 탭 제목 + 개수 + 정렬 알약(선택만 흰 바탕) / 카드 2열 / 하단 탭 바.
- **문제 화면**: 시안(`design-reference.jpeg`) 그대로 — "오늘의 배움" 진행 줄(지금 노랑 원·한 문항 초록 ✓·안 한 문항 테두리 원, 오른쪽 "✓ 자동 저장"·"4 / 8"), 왼쪽 문제 카드(QUESTION 04 테두리 라벨, "차근차근 풀어볼까요?", 설명, sand 식 상자에 수학 서체 큰 식, 개념 칩, 포스트잇 "천천히 풀어도 괜찮아."+병아리, 맨 아래 "나중에 풀기"), 오른쪽 필기 카드(점 격자, 왼쪽 위 "나의 풀이", 오른쪽 위 되돌리기, 아래 도구 알약 + 노란 "풀이 제출하기 →"), 그 아래 작은 병아리 + "풀이 과정이 자동으로 기록되고 있어요." 세로 화면은 문제 카드 위·필기 카드 아래.
- **메시지 위젯**: 💬 바로 아래 오른쪽에 뜨는 카드(폭 ~400, 높이 ~560, 모서리 24, line 테두리, 그림자 반경 24 y10). 헤더 paper(병아리 30 + "선생님께 메시지" + 작은 안내 + 오른쪽 sand 원형 ✕), 대화 영역 cream, 입력 줄 paper(흰 둥근 입력칸 + honeyDeep 원형 화살표). **바깥은 어둡게 하지 않는다.**
- **당겨서 새로고침**: 상단 바 바로 아래 가운데에 paper 알약(병아리 26 + "당겨서 새로고침"/"놓으면 새로고침"/"새로고침 중…"), 옅은 그림자. 화면 자체는 밀려 내려가 잘리지 않는다.
- **축하 화면**: 반투명 크림 흐림 위 paper 카드(병아리 132 + "모든 문항을 제출했어요!" + 안내 + 노란 버튼), 노랑·초록·분홍 색종이.

### 5. 움직임 (가장 중요 — 영상 참고)

원칙: **빠르게 반응하고 탄력 있게 멈춘다.** 누를 땐 즉시(0.08초), 놓을 땐 살짝 튕기며(오버슈트) 돌아온다. 등장은 아래에서 위로·작은 데서 큰 쪽으로. 반복 움직임(병아리)은 느리고 부드럽게. "동작 줄이기"를 켜면 반복·등장 움직임은 끈다.

### 6. 하지 말 것

- 회색 탭 하이라이트, 클릭할 때 화면 전체를 어둡게 덮는 막.
- 기본 UIRefreshControl 처럼 화면을 밀어 내려 위가 잘리는 새로고침.
- 원래 크기보다 작아지는 핀치 축소, 끝에서 튕기는 확대(확대는 최대 5배까지 허용).
- 획을 통째로 지우는 지우개, 손바닥이 그려지는 필기 칸.
- 갑자기 나타나고 사라지는 화면 전환(전부 위 표의 시간·곡선으로).

## 영상 다시 찍는 법 (개발용)

디버그 빌드에는 자동 시연이 들어 있다. 시뮬레이터에서:

```bash
xcrun simctl io booted recordVideo --codec=h264 tour-raw.mov &   # 녹화 시작
xcrun simctl launch booted kr.pulibom.student -loginId s01 -loginPassword 0000 -tour YES -tourAssignment <과제id>
# 1분쯤 뒤 녹화 프로세스에 Ctrl+C (kill -INT)
avconvert --source tour-raw.mov --preset PresetHEVCHighestQuality --start <시작초> --duration 25 --output media/tour.mov   # 앱 부분만 잘라 줄이기
```

시뮬레이터가 느릴 때(맥 부하가 높을 때)는 화면이 늦게 떠서 시연이 어긋난다. 다른 시뮬레이터를 꺼 두고 찍는다.

자동 시연 순서: 시작 화면 → 자동 로그인 → 다 푼 과제 → 지난 과제 → 지금 풀 과제 → 메시지 위젯 열기·닫기 → 당겨서 새로고침 표시 → 문제 화면 → 2번·3번·1번 문항 이동 → 과제 목록.
(지금 녹화본에는 문제 화면 이동 부분이 찍히지 않아서, 문제 화면은 `06-solve.jpg` 로 대신한다.)
