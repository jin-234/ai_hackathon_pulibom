# 풀이봄 학생용 아이패드 앱 — 재현 프롬프트

> **디자인·움직임까지 똑같이** 만들려면 `디자인-모션-가이드/` 의 프롬프트·코드 부록·사진/영상을 같이 준다.
> 아래 "프롬프트" 부분을 통째로 AI 코딩 도우미(Claude Code 등)에게 주면, 지금의 학생용 아이패드 앱과 웹 쪽 연동을 같은 모습으로 다시 만들 수 있게 정리했다.
> 전제: `pulibom-ai-hackathon` 저장소의 `app/` (Next.js 15 App Router + Tailwind v4 + PostgreSQL/Supabase) 웹이 이미 있고, 학생 화면(`/student`, `/student/[assignmentId]`)·교사 화면(`/teacher`)·로그인(`/login`, `/api/auth/login`)·회원가입(`/signup`, `/api/auth/signup`)·필기 캔버스(`InkCanvas.tsx`)가 있는 상태.

---

## 프롬프트

풀이봄(중학생 수학 풀이를 AI로 분석해 교사의 맞춤 지도를 돕는 서비스)의 **학생용 아이패드 앱**을 만들어 줘.
교사는 지금 웹사이트를 그대로 쓰고, 학생은 아이패드 앱으로 수업(과제 풀이)을 한다. 모든 문구는 한국어, 초·중학생에게 말하듯 부드럽게("~해요").

### 0. 큰 구조

- `ios/` 에 **SwiftUI 앱**(iPad 전용, iOS 17+, Xcode 26)을 만든다. 앱은 **네이티브 껍데기 + WKWebView** 구조:
  - 네이티브: 시작 화면, 서버 주소 설정, 로그인, 회원가입, 상단 바, 하단 탭 바, 선생님 메시지 위젯, 당겨서 새로고침 표시.
  - 웹뷰: 풀이봄 웹의 학생 화면(`/student`…)을 띄운다. 학생 화면을 웹에서 고치면 앱에도 바로 반영된다.
- Xcode 프로젝트는 **파일 시스템 동기화 그룹**(`PBXFileSystemSynchronizedRootGroup`, objectVersion 77)으로 직접 작성해서 `ios/Pulibom/` 폴더에 파일을 넣으면 자동 포함되게. `Info.plist` 는 동기화 폴더 밖(`ios/Info.plist`)에 두고 `GENERATE_INFOPLIST_FILE=YES` 와 합친다.
  - Bundle ID `kr.pulibom.student`, 표시 이름 `풀이봄`, `TARGETED_DEVICE_FAMILY=2`, 네 방향 회전 모두 지원, 자동 서명(`CODE_SIGN_STYLE=Automatic`).
  - Info.plist: `NSAppTransportSecurity` 에 `NSAllowsArbitraryLoads`·`NSAllowsLocalNetworking` true (맥에서 http 로 돌리는 개발 서버 접속), `NSLocalNetworkUsageDescription` "같은 와이파이에 있는 풀이봄 서버(선생님 컴퓨터)에 연결하려고 필요해요.", `UILaunchScreen` → `UIColorName = LaunchBackground`.
- 에셋: `AppIcon`(1024 한 장: 연노랑 #FBEDBD 바탕 + 웹의 `Chick.tsx` 새싹 병아리 SVG를 sharp 로 PNG 렌더), `Chick`(투명 배경 새싹 병아리 300px @3x), `AccentColor`(#E2B53C), `LaunchBackground`(#FBEDBD).
- 앱 전체 `.preferredColorScheme(.light)` (다크 모드여도 글자가 흰색이 돼서 안 보이지 않게). 앱이 켜져 있는 동안 `isIdleTimerDisabled = true`(수업 중 화면 안 꺼짐).

### 2. 공통 디자인 부품 (`DesignKit.swift`)

- `FormGroup` / `FormRow(label:last:)`: iOS 설정 앱 같은 둥근 묶음(paper 바탕, line 테두리, 모서리 20). 줄 높이 56, 왼쪽 라벨 폭 84, 오른쪽 값은 `.title3`·ink·커서 honeyDeep, 줄 사이 1px line.
- `MenuValue(text:)`: 값(ink) + `chevron.up.chevron.down`.
- `PrimaryButton(title:busy:disabled:)`: honey 바탕, 높이 56, 모서리 18, 비활성 시 투명도 0.5.
- `Notice(text:kind:)`: 오류(salmon)·성공(sage) 알림 박스.
- `PressableStyle`(`.pressable`): 누르면 0.08초 만에 96%·투명도 0.85, 떼면 스프링(response 0.32, damping 0.55)으로 돌아옴. 모든 커스텀 버튼에 사용.
- `.bobbing()`: 위로 10pt 떠오르며 -4°↔3° 기울기, 1.5초 easeInOut 반복 (동작 줄이기면 끔).
- `.riseIn(delay:)`: 처음 나타날 때 투명+아래 18pt → 스프링으로 제자리.
- `.matchedLogo(ns, isSource:)`: 시작 화면 병아리 ↔ 로그인 병아리 `matchedGeometryEffect(id: "logo-chick")`.

### 3. 화면 흐름 (`ContentView.swift`)

`@AppStorage("serverURL")` 가 비었으면 서버 주소 설정 화면. 있으면 `student == nil` 이면 로그인, 있으면 학생 화면(셸). 그 위에 시작 화면을 한 번 덮는다.
- 로그인 성공/로그아웃 전환은 `withAnimation(.easeInOut(0.35))` — 로그인 화면은 `.opacity + .scale(0.97)`, 셸은 `.opacity + .move(edge: .trailing)`.
- 서버 주소가 바뀌면 로그아웃 상태로.
- 웹 로딩 실패 시 연결 실패 화면(🐣, 주소, 오류, "맥과 아이패드가 같은 와이파이에 있는지…", [서버 주소 바꾸기] [다시 시도]).

### 6. 로그인 (`LoginView.swift`) — 앱을 켤 때마다 새로 로그인

(아이패드 한 대를 여러 학생이 돌려 써도 누가 푸는지 남도록. 들어올 때마다 웹뷰 쿠키를 모두 지운다.)
- 레이아웃: **가로**면 왼쪽 44% 영웅 영역 + 오른쪽 입력, **세로**면 위 34% 영웅 영역 + 아래 입력. 세로에서 비밀번호 칸에 포커스가 가면 영웅 영역을 0으로 접어(애니메이션) 키보드에 가리지 않게.
- 영웅 영역: honeySoft→honey(0.55) 그라데이션, 병아리(가로 180/세로 110, `.bobbing()`, 시작 화면과 matched), "풀이봄."(44/32pt), "풀이를 모아, 배움을 잇다".
- 입력 영역(최대 폭 440): 큰 제목 "로그인", "반과 번호를 고르고 비밀번호를 넣어 주세요."(`.riseIn()`), 그 아래 `FormGroup`(`.riseIn(delay: 0.08)`):
  - **반**: Menu+Picker. 반을 바꾸면 그 반 첫 학생으로.
  - **번호**: Menu+Picker, **번호만 표시("7번")**, 이름은 보이지 않게.
  - **비밀번호**: SecureField(오른쪽 정렬, 숫자 키패드, 숫자만 최대 8자리, placeholder "숫자").
  - 오류 Notice, `PrimaryButton("과제 풀러 가기")`(비밀번호 비면 비활성), "처음 왔나요? **반 코드로 회원가입**"(honeyDeep) → 회원가입 시트, 작게 "로그인 건너뛰고 둘러보기", "데모 계정 · 학생 번호 선택 후 **0000**".
- 오른쪽 위 ⚙︎ → 서버 주소 설정. 명단 불러오기 실패 시 Notice + [서버 주소 바꾸기][다시 시도].
- 명단: `GET /api/roster` → `{students:[{id, number, name, classId, className}]}`.
- 로그인: `POST /api/auth/login {role:"student", id, password, skip}` 를 ephemeral URLSession 으로 보내고, 응답의 `Set-Cookie`(세션 쿠키 `pulibom_session`)를 `HTTPCookie.cookies(withResponseHeaderFields:for:)` 로 읽어 **`WKWebsiteDataStore.default().httpCookieStore` 에 넣는다** → 웹뷰가 같은 학생으로 열린다.

### 7. 회원가입 시트 (`SignupView.swift`)

NavigationStack, 제목 "회원가입", 왼쪽 위 [취소]. 묶음 3개:
- **반 코드**(영문 대문자·숫자 6자리, 모노스페이스, 자간): 6자리가 되면 `GET /api/auth/signup?code=` 로 반 이름을 받아 초록 Notice("✓ 2026학년도 1학년 3반"), 틀리면 빨간 Notice.
- **내 정보**: 번호(숫자 2자리), 이름(20자).
- **비밀번호**: 숫자 4~8자리 + 확인(다르면 "비밀번호가 서로 달라요.").
- `PrimaryButton("가입하고 과제 보러 가기")` → `POST /api/auth/signup {code, number, name, password}`, 쿠키를 웹뷰로 넘기고 바로 로그인 상태로.

### 8. 학생 화면 셸 (`StudentShellView.swift`)

세로 스택: **상단 바(64pt)** / 웹뷰 / (과제 목록일 때만) **하단 탭 바**.
- 상단 바 왼쪽: 과제 목록(`/student`)에선 병아리+"풀이봄.", 문제 푸는 중엔 "‹ 과제 목록" 알약 버튼(보던 탭으로 돌아감).
- 상단 바 가운데: 문제 푸는 중이면 웹 문서 제목(= 과제 이름, `webView.title` KVO)을 " · " → " / " 로 바꿔 표시.
- 상단 바 오른쪽: **💬 메시지 버튼**(원형, 안 읽은 수 빨간 배지·bounce) + 이름 알약(이름 + 첫 글자 원). 이름 알약은 Menu: 서버 주소 설정 / 로그아웃(확인 다이얼로그 "OO 학생, 로그아웃할까요?" → 쿠키 지우고 로그인 화면).
- 하단 탭 바: **지금 풀 과제(pencil.line) / 다 푼 과제(checkmark.circle) / 지난 과제(clock.arrow.circlepath)**. 선택 표시는 honeySoft 둥근 사각형이 `matchedGeometryEffect` 로 미끄러지듯 이동, 탭할 때 가벼운 햅틱. 문제 푸는 중엔 탭 바를 아래로 숨겨 필기 칸을 넓게.
- 당겨서 새로고침 표시 `RefreshBadge`: 화면을 밀어 내리는 기본 UIRefreshControl 대신, 웹뷰 상단에 작은 알약(병아리+문구)이 당긴 만큼 내려오고 커짐 — "당겨서 새로고침" → "놓으면 새로고침"(그 순간 햅틱) → 놓으면 "새로고침 중…"(병아리 빙글빙글). 다 불러오면 사라짐.

### 9. 웹뷰 (`StudentWebView.swift`)

- `applicationNameForUserAgent = "Mobile/15E148 PulibomApp/1.0"` — 웹이 앱인지 알아보는 표시.
- 문서 시작 시 주입: `[data-app-hide]{display:none!important}.app-only{display:inline-flex!important}` 스타일 + 빈 `touchstart` 리스너(iOS 웹뷰가 버튼 `:active` 를 바로 보여 주도록).
- 문서 끝 주입: viewport 를 `width=device-width, initial-scale=1, minimum-scale=1, maximum-scale=5, user-scalable=yes` 로 고정하고 MutationObserver 로 웹이 바꿔도 되돌림, 길게 눌러 선택·콜아웃 막기(입력칸 제외).
- 확대는 최대 5배, **원래 크기보다 작게는 안 줄어들고 끝에서 튕기지 않게**(`minimumZoomScale=1, maximumZoomScale=5, bouncesZoom=false`), 이동할 때마다 다시 적용.
- `scrollView.delaysContentTouches = false`(버튼 눌림이 늦게 툭 나타나지 않게). 문제 푸는 화면(`/student/…`)에선 `bounces=false`(펜슬 획이 끊기지 않게, 새로고침도 꺼짐).
- 주소 KVO: `/login` 으로 가면(웹에서 로그아웃·세션 만료) 앱 로그인 화면으로. `/student` 면 `?tab=` 을 읽어 하단 탭과 맞춤.
- `WebController`(ObservableObject): `path`, `tab`, `title`, `pull`, `refreshing`. `open(path, tab:)` 는 웹이 준비됐다는 표시 `window.__pulibomReady`(StudentTabs·StudentApp 가 처음 그려진 뒤 true 로)와 `window.next.router.push` 가 둘 다 있을 때만 그걸로(깜빡임 없는 이동), 아니면 `location.assign` — 준비 전에 Next 라우터를 부르면 "Router action dispatched before initialization" 오류가 난다. `switchTab(t)` 는 웹에 `window.__pulibomTabs` 가 있으면 `window.dispatchEvent(new CustomEvent('pulibom:tab',{detail:t}))`(서버 왕복 없이 즉시 전환), 없으면 이동.
- `alert`/`confirm` → UIAlertController. 서버 밖 링크는 사파리로. `target=_blank` 는 같은 화면에서. 콘텐츠 프로세스가 죽으면 reload. 세 손가락 1초 길게 누르기(cancelsTouchesInView=false) → 서버 주소 설정.
- 개발용(DEBUG 빌드만) 실행 인자: `-demoLogin YES`, `-loginId s01 -loginPassword 0000`, `-startPath /student/과제id`, `-openChat YES`, `-tour YES -tourAssignment 과제id`(자동 시연: 탭 넘김 → 메시지 위젯 → 새로고침 표시 → 문제 화면).

### 10. 선생님께 메시지 (`ChatWidget.swift` + 셸의 `chatPanel`)

- 💬 를 누르면 그 바로 아래 오른쪽에 **떠 있는 카드 위젯**(팝오버 아님): 폭 min(400, 화면-32), 높이 max(240, min(560, 남은 높이-80)), 모서리 24, line 테두리, 그림자, 오른쪽 위 기준으로 0.85 배에서 커지며 등장. `GeometryReader` 가 키보드 안전 영역을 따르므로 **키보드가 올라오면 위젯 높이가 줄어 입력 칸이 늘 키보드 위**에 있다. 바깥은 어둡게 하지 않고(투명 + contentShape) 눌리면 닫힘, 닫을 때 키보드도 내림. 💬 를 다시 눌러도 닫힘.
- 위젯: 헤더(병아리, "선생님께 메시지", "궁금한 점을 편하게 물어보세요", ✕), 대화 목록, 입력 줄(여러 줄 TextField "선생님께 보낼 말" + `arrow.up.circle.fill` 보내기, 보내면 햅틱).
- 말풍선: 내 것은 오른쪽 honey, 선생님 것은 왼쪽 paper+테두리(위에 선생님 이름). 보낸 쪽 아래 모서리만 덜 둥근 `BubbleShape`. 아래 시간("a h:mm", 오늘이 아니면 "M/d a h:mm") + 내 메시지는 "· 읽음". 새 말풍선은 해당 모서리에서 튀어나오며 맨 아래로 스크롤, 입력 칸 포커스 때도 맨 아래로. 대화가 없으면 둥실 병아리 + 안내.
- 열려 있는 동안 4초마다 대화를 새로 가져오고, 닫혀 있을 땐 15초마다 안 읽은 수 확인.
- 네이티브에서 API 를 부를 땐 웹뷰 쿠키 저장소의 쿠키를 `Cookie` 헤더로 붙인다(`httpShouldHandleCookies=false`).
- 둘러보기(데모) 계정이면 "둘러보기 중에는 메시지를 쓸 수 없어요. 내 번호로 로그인해 주세요."

### 11. 웹(`app/`) 쪽 바꿀 것

**앱 연동**
- `src/lib/app.ts`: `APP_UA = "PulibomApp"`, `isAppUA(ua)`.
- `middleware.ts`: 앱 UA 로 `/` 나 `/teacher…` 에 오면 학생이면 `/student`, 아니면 `/login?role=student` 로. matcher 에 `/` 추가.
- 로그인 페이지: 앱이면 학생 탭만, 데모 안내도 학생 것만.
- `GET /api/roster`: 로그인용 학생 명단(id, number, name, classId, className).
- 학생 화면 상단 바 중 로고·과제 목록·이름·로그아웃(문제 화면은 상단 줄 전체)에 `data-app-hide` → 앱에선 숨김. 앱 전용 요소엔 `.app-only`(웹 기본 `display:none`).
- 문제 화면 `generateMetadata` 로 `title = 과제 이름` (앱 상단 바 가운데에 표시).

**학생 과제 목록 (`/student`)**
- `?tab=todo|done|past` 면 한 묶음만(앱 기본 todo, 웹은 탭 없으면 한 화면에 셋 다). 세 탭 내용을 미리 다 받아 두고 `StudentTabs` 클라이언트 컴포넌트가 화면에서만 바꿈(고른 방향에서 28px 밀려 들어오며 0.32s 페이드, 주소는 `history.replaceState` 로 `?tab=` 갱신, `pulibom:tab` 이벤트 수신, `window.__pulibomTabs=true`).
- 탭 제목 오른쪽 정렬 칸 `SortPicker`: 최신순/오래된순/이름순(제목 `localeCompare("ko",{numeric:true})`), '지금 풀 과제'엔 마감순도(기본). 고른 값은 쿠키 `student_sort` 에 1년 기억. 정렬 상수는 서버·클라이언트가 같이 쓰도록 `src/lib/studentSort.ts`("use client" 파일에서 서버로 값을 가져오면 프록시라 안 읽힘).
- 빈 탭: 둥실 병아리 + "아직 다 푼 과제가 없어요." 등. 인사말 병아리도 둥실.

**문제 푸는 화면 (`StudentApp.tsx`) — 시안대로**
- 화면 높이에 딱 맞춤(`h-[100dvh]`). **가로**(`md:landscape:`)면 왼쪽 문제 칸(300~360px) | 오른쪽 필기 칸, **세로**면 문제 칸(최대 42dvh, 스크롤) 위 / 필기 칸 아래. 너비가 아니라 실제 방향 기준(13인치도 세로면 위아래).
- 웹 상단 바(앱에선 숨김): 왼쪽 로고·과제 목록, 가운데 "수학 1-1 / 일차방정식", 오른쪽 "✓ 자동 저장됨" 알약·이름 원·로그아웃.
- 진행 줄: "오늘의 배움"(마감 과제면 "채점 결과") + 문항 원(지금=honey, 낸 것=sage ✓ — ✓는 톡 튀며 등장) + 오른쪽 자동 저장 알약(.app-only)·마감 시각·"4 / 8".
- 문제 칸: "QUESTION 04" 테두리 라벨, "차근차근 풀어볼까요?"(2xl extrabold), "다음 일차방정식을 풀고, 풀이 과정을 써 보세요.", 큰 식 상자(sand, 수학 서체 4xl), 개념 칩, 작은 쓰기 안내("한 줄에 식 하나씩, 마지막 줄에 x = □"), 낸 문항이면 "✓ 제출한 풀이예요. 고쳐서 다시 제출할 수도 있어요.", 포스트잇("천천히 풀어도 괜찮아." + 연필 든 둥실 병아리, 가로에서만), 맨 아래 "나중에 풀기"·타이머. 문항을 옮기면 문제 칸이 옆에서 밀려 들어옴.
- 필기 칸 아래: 작은 병아리 + "풀이 과정이 자동으로 기록되고 있어요."
- **다시 풀기·자동 저장**: 서버에서 문항별 마지막 제출 획(`latestStrokes`, 쿼리 한 번)을 받아 시작. 문항을 옮길 때 쓰던 획을 기억. 쓰기·지우기·되돌리기마다 `localStorage["pulibom:draft:{학생id}:{문항id}"]` 에 저장해 앱을 껐다 켜도 이어 씀, 제출하면 지움.
- **다 끝냈을 때**: alert 대신 축하 오버레이 — 색종이 36개(노랑·초록·분홍, 회전하며 떨어짐), 카드가 튀며 등장, 통통 뛰며 날개 파닥이는 새싹 병아리(132), "모든 문항을 제출했어요!", "수고했어요. 선생님이 곧 풀이를 확인해 줄 거예요.", [과제 목록으로 →]. 3.2초 뒤 자동 이동, 아무 데나 눌러도 이동.

**필기 캔버스 (`InkCanvas.tsx`) — 애플펜슬 최적화**
- **펜슬 전용**: `pointerType === "touch"` 는 무시(마우스는 허용). 손가락으로 대면 "✏️ 애플펜슬로 써 주세요" 알약이 1.8초 떴다 사라짐.
- 캔버스 두 장: 아래(다 쓴 획) + 위(지금 쓰는 획·지우개 원, 입력도 위가 받음). 쓰는 동안 위 캔버스만 rAF 로 다시 그림.
- `getCoalescedEvents()` 로 펜슬의 촘촘한 좌표를 모두 사용, 시각은 `performance.timeOrigin + e.timeStamp`. 점 사이는 중점을 지나는 `quadraticCurveTo` 곡선. 캔버스 해상도는 devicePixelRatio(최대 3)에 맞추고 그리기 좌표는 1000×680 그대로. 펜슬 호버는 무시(그리는 중인지로 판단).
- 캔버스 터치 기본 동작을 `touchstart/move/end` 에서 `preventDefault`(passive:false) — 스크리블·확대·길게 누르기가 획을 끊지 않게.
- 쓰는 칸은 1000:680 비율을 지킨 채 남은 자리에 최대 크기: 바깥 `container-type:size`, 안쪽 `width: min(100cqw, calc(100cqh*1000/680))`, `aspect-ratio`.
- **지우개는 지나간 자리만**: 원(얇게 반지름 15, 굵게 30, 획 굵기 절반까지 포함)과 선분의 교점을 계산해 획을 그 자리에서 잘라 조각으로 나눔(서버 OCR 이 획 좌표로 다시 그려 읽으므로 데이터에서도 지워져야 함). 지나간 경로를 r/3 간격으로 촘촘히 적용, 지우는 동안 지우개 원 표시, 손을 떼면 저장. 기록엔 원래 획 id 만 erase 이벤트로.
- 실행취소·다시실행은 "바뀌기 전 획 전체" 스냅숏 스택으로(잘린 획도 그대로 복원). `onChange` 콜백(자동 저장용), `getStrokes()`, `reset(strokes?)`.

**선생님 ↔ 학생 메시지**
- DB `db/init/10_messages.sql`: `messages(id bigserial, student_id → students, sender 'student'|'teacher', sender_id, sender_name, body 1~1000자, created_at, read_at)`, `(student_id, id)` 인덱스, RLS 켬. 학생 한 명당 대화방 하나, 지금 담당 선생님들이 함께 봄.
- `src/lib/messages.ts`: `listMessages`(최근 200개), `sendMessage`, `markRead(studentId, reader)`, `studentUnread`, `teacherInbox(teacherId)`(지금 담당 반 학생이 보낸 안 읽은 메시지, 학생별 개수·마지막 내용).
- API: `GET/POST /api/messages`(학생 본인, `?unread=1` 이면 수만, 열면 선생님 메시지 읽음 처리, 데모 계정 불가), `GET/POST /api/students/[id]/messages`(선생님, 읽기는 지난 학년 학생도, 보내기는 지금 반만), `GET /api/messages/inbox`.
- 선생님 웹: 상단 바에 `TeacherInbox`(말풍선 아이콘 + 빨간 안 읽은 수, 20초마다 확인, 누르면 학생별 목록 → `/teacher/students/{id}?tab=messages`), 학생 상세에 "메시지" 탭 `MessageThread`(5초마다 새로 고침, 선생님 말 오른쪽 honey, "· 읽음").

**누르는 느낌·움직임 (`globals.css`)**
- `-webkit-tap-highlight-color: transparent`, 모든 버튼·링크 `touch-action: manipulation` + `:active` 에서 0.08초 만에 96%, 떼면 `cubic-bezier(0.34,1.56,0.64,1)` 0.32s 로 탄력 복귀(큰 카드 링크는 98.5%).
- 과제 카드 `.stagger`: 하나씩 0.05s 간격으로 아래 16px 에서 올라옴(`animation-fill-mode: backwards` — 끝나면 :active 누름 효과가 그대로 동작하게).
- 병아리(`Chick.tsx` 에 `motion?: "bob" | "cheer"`): bob = 3.2s 둥실(위로 9%, 좌우 ±5° 번갈아) + 3.8s 마다 눈 깜빡, cheer = 0.62s 통통 점프(늘고 찌그러짐) + 날개 파닥. 모두 `prefers-reduced-motion` 이면 끔.

### 12. 실행·설치

- 맥에서 `cd app && npm run dev`, 앱 서버 주소는 `맥IP:3000`(`ipconfig getifaddr en0`). 시뮬레이터는 `localhost:3000`.
- 실제 아이패드: 케이블 연결 → 신뢰 → 설정 › 개인정보 보호 및 보안 › 개발자 모드 켜기 → Xcode 에서 기기 선택·Team 지정 → ▶︎ (또는 `xcodebuild -destination 'generic/platform=iOS' -allowProvisioningUpdates build` 후 `xcrun devicectl device install app`).
- 브랜치를 합치거나 패키지를 올린 뒤 개발 서버가 `Cannot find module './NNNN.js'` 를 내면 서버를 끄고 `app/.next` 를 지운 뒤 다시 켠다.
